# Task 01 handoff — scaffold

Implemented on 23 October 2026 in `worldraft`.

## What works

- One root `npm run dev` command starts FastAPI and Vite after first-time dependency setup.
- Readiness checks include the browser's proxied health route; one browser launch is attempted after readiness.
- A responsive studio shell displays a Three.js cube/grid fixture, Layers, Properties, disabled generation controls and live backend connectivity.
- LangChain is installed; a typed one-node LangGraph compiles and runs without a model.
- Configurable ports, no-open mode, setup errors, port conflicts, readiness timeout, service failure cleanup and owned process-group shutdown are implemented.
- Both dependency ecosystems are locked. No LLM, Blender, external art, map data or telemetry is required.

## Environment-specific cleanup limitation

The first interactive previews were started by the agent at ports 8000/5173 and 8011/5181. The agent environment denied signalling those already-running sessions; automatic approval review also rejected a later Ctrl+C request because sandbox approval was disabled. These restrictions are separate from the launcher integration tests, whose fresh subprocesses shut down correctly inside their own test execution.

If these preview processes are still running, stop them from your own terminal before starting a new default-port session. Inspect ownership first with `lsof -nP -iTCP:8000 -iTCP:5173 -iTCP:8011 -iTCP:5181 -sTCP:LISTEN`. Only stop processes you identify as this Worldraft preview. Use alternate ports if you want to leave the preview running.
